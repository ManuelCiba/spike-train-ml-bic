# Description
Codebase for the publication:
Ciba, M., Petzold, M., Alves, C. L., Rodrigues, F. A., Jimbo, Y., & Thielemann, C. (2025). Machine learning and complex network analysis of drug effects on neuronal microelectrode biosensor data. Scientific Reports, 15(1), 15128.

Download: https://www.nature.com/articles/s41598-025-99479-7

# How to use
- Install packages using "requirements.txt".
- Run the script "main.py".
- Please note, that the source data folder is not included.
